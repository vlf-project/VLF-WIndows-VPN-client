# Privacy Overview

This repository publishes Windows client release/documentation materials, not the client source code.

A formal independent third-party security audit has not yet been completed.

The Windows client may process VPN subscription/profile configuration locally, including subscription links, protocol credentials, routing settings, deep-link imports, logs and update checks as described by the README.

The client should not publish subscription links, profile credentials, UUIDs, tokens or logs without user action and redaction.

No traffic resale, traffic injection or ad injection is intended by project policy. This repository does not contain source code that independently proves that behavior.

## Data Retention

This repository does not define server-side retention policy. See service-level privacy policy.

Local retention depends on the installed Windows client behavior and is not fully defined in this release/documentation repository.
