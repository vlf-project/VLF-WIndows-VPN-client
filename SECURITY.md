# Security Policy

This repository contains release builds and documentation for the Windows VLF Secure Connect client. The README states that application source code is private and not publicly available here.

A formal independent third-party security audit has not yet been completed. Responsible disclosure is welcome.

## Supported Versions and Branches

| Branch or version | Status |
| --- | --- |
| `main` | Documentation/release metadata support |
| Latest Windows release build | Supported for user-facing security reports |
| Older release builds | Best-effort only |

## Scope

In scope:

- Published Windows release assets and documentation.
- Deep-link import behavior described in README.
- User-facing security issues reproducible in release builds.

Out of scope unless tied to a released VLF build:

- private source-code review not present in this repository;
- social engineering;
- attacks against third-party VPN providers, GitHub Releases or Windows itself.

## Safe Harbor

Good-faith research is welcome when it uses your own device, accounts and synthetic profiles.
